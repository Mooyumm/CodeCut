# CodeCut 发布说明

## 1.0.1 开发中

- 新增「音乐参考」工作区：跨项目参考曲入库、波形拖选多片段、循环试听、逐段批注与自动保存；按批注调用本地模型生成用途分类和可编辑的英文音乐提示词。结果区分用户描述与编曲建议，明确不代表音频实测。支持批量生成、过期结果提示，以及片段 M4A＋TXT 批注＋JSON 导出。参考音频保留本机副本，参考库带备份恢复。

- **分镜页新增「AI 排 B-roll」**：按分镜稿的「镜头类型」和「分镜」描述，从 B-roll 库里挑素材排到分镜时间线上。位置规则只有一条——片段的入点就是这句台词开始的时间；长度不强行去盖住台词，而是从本机模型挑出的那个入点一直播到这条素材结束，于是相邻两条经常叠住，同一时刻放不下才多开一条轨道（轨道按时间顺序先塞已有的，塞不下才新开，越少越好）。点「清除排片」或 ⌘Z 可以整体撤销。挑选分两步：先在本地按画面标签／画面结论／物品清单用两字组合粗筛出候选（台词、镜头类型、分镜备注都参与），再由本机模型在候选里定夺——模型说“都不合适”的行留空，模型没给结论的行才退回本地最接近的一条并注明是兜底。素材内部从本机模型认定的“最清楚那一段”开始用。标了「未拍摄／网络素材」的镜头不参与排片（那类镜头本来就要去库外找）；同一段素材不会被反复用，只有库里挑不出别的了才允许复用。拿真实项目（29 行分镜稿、51 条 B-roll）实测：排上 21 条、跳过 3 行网络素材镜头，5 行库里确实没有对应素材留空，用时约 19 秒（本机模型逐批挑选，不联网）。
- **分镜稿按口播对时间**：分镜页（和文稿页）的分镜稿工具栏新增「匹配口播时间」按钮（⇧⌘T）。点一下就在「文稿」列后面插一列「时间」，逐行把这一句台词在成片里的时间区间写进去（`01:04.3–01:08.9`）；口播里没说到的那一行留空。时间用的是成片时间，和分镜时间轴、字幕轨道同一套，删掉的气口和掐掉的头尾已经扣掉。口播或剪辑变了（重新转写、删词、删气口、掐头尾）会在打开这一页时自动重对一次；导入或手写的时间列不会被动，想重算就点按钮。对齐全部在本机完成，不联网、不调模型：先按 3 字／2 字组合圈出候选区间，再在区间里做局部对齐（一致 +3、不一致 -1、空位 -2），覆盖率不到一半就判为「口播里没有」。拿真实项目（29 行分镜稿、1105 个词）实测 29/29 行全部对上，耗时 59 毫秒；同一份数据交给本机 Qwen3-VL 4B 模型一次要 40 秒，还会串行和凭空多编一行，所以这一步没有交给大模型。
- 断句改为「纯文本进、逐字回」：交给 DeepSeek 的是去掉全部 `[序号]` 的连续原文，让它只插换行，返回后再用带子编辑距离逐字对齐回逐词稿的 UUID。模型看到的是正常中文而不是 `[0]这[1]也[2]是` 的标记流；返回原文只允许极少量改动（约 0.5%，且不少于 2 处），改动过多判定不可信并重试，仍失败则自动退回逐词序号方案。
- 长稿按章节切窗口分批断句：先按 ≥0.9 秒的长停顿定章节，再按约 1200 字打包成窗口，必要时在章节内部顺着较大停顿再切；每个窗口前后各带 120 字上下文（`<before>` / `<after>`，明确要求模型不为上下文换行、不抄进结果）。窗口接缝落在说话人自己的呼吸上，不会切坏句子；某一窗口失败只退那一段到逐词序号方案，其余窗口照常生效。
- DaVinci Resolve EDL 为每个剪辑分别写入视频轨和音频轨事件，避免导入后只有画面。
- 重新断句不再机械接受固定字数换行；结合自然语音停顿、中文重新起句、词法安全边界和参考稿语义，并保护数字、量词及英文产品名不被拆开。
- 断句拆成三级，先便宜后贵：**第一级文稿标点**（把文字稿的标点按逐字对齐贴回没有标点的识别稿，对齐不可信时整级作废，绝不拿错标点去切）、**第二级真实停顿**（直接用逐字时间戳找停顿，纯算法零延迟）、**第三级本地模型**（只处理前两级没解决的长句，还没接）。
- 「重新断句」不再只看字数：在窗口内优先挑 ≥0.28 秒的真实停顿当断点，挑不出停顿才退回按字数均衡切，时长严重超标又没有停顿时放宽到 ≥0.12 秒。修掉旧逻辑最长能出一条 8 秒字幕、只看字数不看时长的问题。
- 新增「本地断句」按钮（素材面板与字幕面板各一个）：只用文稿标点和真实停顿重排断句，完全不调用任何模型，断网可用、不消耗额度；有可用文稿时提示「已对照文稿标点」，没有时提示「仅按停顿和自然语言规则」。
- 文稿改动后不自动重排断句，需要时手动点一次「重新断句」或「本地断句」，避免识别稿被意外改写。
- DeepSeek 断句改为只返回逐词序号，不再回传整篇原文，避免长稿中改字或标点导致断句结果被拒绝。
- 去重字幕行新增“保留”，行内删除只作用于当前字幕；最终保留版本不会再次成为待删候选。
- 只保留 DeepSeek 一个 AI 入口：设置页移除提供商选择、MiMo Base URL 与 ASR 模型字段，钥匙串条目迁移到 com.codecut（旧条目自动读取一次）。
- **DeepSeek 云端接口已关闭**：设置页不再有 API Key / Base URL / 模型名，改成显示本机模型状态，可以“准备本地模型 / 检查状态 / 测试连接”。所有 AI 动作（审稿、去重分析、分镜提示词、对话）改由本机 Qwen3-VL 8B 承担，调用前自动把 llama-server 拉起来；没装运行时或权重会给出明确提示，不再需要联网、也不再需要任何 Key。
- 断句在关闭云端后只走本机规则（文稿标点 + 真实停顿），不再给模型发请求：实测同一个断句提示词，本机模型在 1200 字窗口下 41 秒只返回一行（完全不切），降到 300 字窗口虽然能切出 19 行，但返回原文与识别稿有约 5 个字的出入、超过对齐容差会被判为不可信，所以断句不交给它做。素材面板和字幕面板的“重新断句”因此合并成一个按钮，文案写明“全部在本机完成”。
- 本机后端的请求超时放宽到 900 秒（云端仍是 120 秒），并且不再发送 DeepSeek 专有的 `thinking` 字段。DeepSeek 的代码保留在 `AISettings.deepSeek` 里，随时可以切回去。
- 修复项目栏按钮失效：侧栏“＋ / 新建项目… / 打开其他项目…”与顶部“新建 / 导入 / 打开”恢复可用（此前 .fileImporter 在手写 AppKit 宿主下不触发），并新增“文件”菜单（⌘N 新建、⌘O 打开、⌘I 导入素材）。
- 剪气口新增“停顿”档位（剪掉 / 紧凑 / 标准 / 舒缓，默认标准：句末留 0.3 秒、章节处留 0.8 秒），实现方式是在删除区间末尾退还静音；章节按 0.9 秒以上长停顿或句末标点判定，设置随项目保存。
- 新增“头尾”档位：默认剪掉片头片尾没有台词的部分（只按“停顿”档位留出前导/收尾，标准档前后各 0.3 秒），切到“保留”即可放回，设置随项目保存。
- 去重新增“有序重合”判据：半句后重说整句、补入“的/是/了”或近处换序的重录，即使字符编辑距离和二元组重合都不达标也能识别；候选按结束时间从后往前处理，同一段重录的多个版本只保留最后一遍。
- 新增 **B-roll 工作区**（底部工作区切换条：口播 / B-roll / 分镜）。可以一次多选视频，也可以直接选整个 B-roll 文件夹（递归扫描）；只登记路径和元数据，不复制、不转码原文件，素材随项目保存。
- B-roll 的**内容和运动方向识别全部在本机完成**，用的是 macOS 自带的 Apple Vision，不联网、不下载模型、不需要额外安装任何东西：画面内容走 `VNClassifyImageRequest` 场景/物体分类，运动方向走 `VNGenerateOpticalFlowRequest` 稠密光流。
- **运动曲线（量化，不用文字形容）**：除了“向右移动”这种一句话结论，每条素材还会密集采样 24 个点逐对算光流、积分成完整轨迹，给出：轨迹图（画面宽高百分比坐标，颜色从蓝到橙表示时间先后）、速度曲线（点一下跳到那一刻）、以及**运动阶段**——在哪些区间里是静止 / 匀速移动 / 加速 / 减速 / 来回晃动。剪辑真正能用的是一个区间，不是一个全片平均值；素材卡片上还有一条速度缩略曲线，不用点开就能看出这条是“一直很稳”还是“中间动了一下”。
- 运动方向按“观众看到的方向”给结论（固定镜头 / 向上 / 向下 / 向左 / 向右 / 斜向 / 往复移动），位移量是首尾两帧之间的累计位移，单位换成画面宽高的百分比，所以 4K 和 1080p 的判断一致；变焦（推近 / 拉远）单独作为一维，因为它和横移是两件不同的事。识别结果里同时保留水平/垂直位移、每秒位移、发散度和画面活跃度，方便自己复核。
- 判定阈值是在真实素材上标定的：先算首尾两帧的整体位移而不是把相邻帧位移加起来，避免光流噪声累积；“先移动后停住”能算成整段位移，“来回移动”会因为前后半段方向相反判成往复而不是单向。对极端近景（分类器给不出高置信度标签的产品特写）用画面明暗/色调兜底，保证每条素材至少有一个可读描述。
- B-roll 媒体库支持按内容、方向或文件名搜索，按运动方向筛选；缩略图按需生成并限制并发解码，几十条 4K 素材同时进列表也不会把机器拖住。识别是逐条写回、可随时停止的，中途取消会保留已完成的结果。
- B-roll 库的增删改会随项目自动保存；缩略图只放在内存里，不进项目文件。
- 去重按“鱼骨图”分叉判断：没读错的那一遍是主干，节点上重复的几遍是分支。分支只有一句或半句（≤45 字、≤12 秒、≤2 句）＝读错重录，自动去重直接保留最后一遍；分支是成段的好几句话＝可能是在试不同语气，不再自动删除，改成卡片列出“较早录的这一版 / 后面重录的这一版”，试听后由你选留哪一版（批量“全部删除”也会跳过这些，必须逐条选）。
- 产品镜头挑选：B-roll 工作区新增“产品档案”，把品牌方的 brief（PDF）交给本机视觉模型读完，自动得出产品是什么、长什么样、要认的特征、容易认错的干扰项，并从 brief 里挑出产品图当参考图。
- **认出画面里的物品**：识别不再只回答“有没有拍到目标产品”。每条素材仍然只看 5 个采样点，但每个采样点会列出一张物品清单——这一帧里每件东西分别是什么（产品清单里的第几号、什么颜色）、扮演什么角色（主体 / 陪衬 / 背景装饰 / 拍摄设备 / 看不出是什么）、大致在画面什么位置、在画面里清不清楚；再按“最清楚的那件就是焦点所在”汇总出这条素材的主角，以及焦点在哪几个时间点换了人（对焦转移）。
- **B-roll 分成两栏：左边全部素材，右边按产品分组**。左栏只回答“素材都在不在”（导入、搜索、状态点、识别按钮），刻意不分类；右栏按认出来的产品一款一个文件夹，卡片上直接标着这条素材属于哪几个产品——一条素材里出现了两个产品，它就会在两个文件夹里各出现一次（同一份素材，不是副本）。**分组是实拍的结果**：brief 里给了三个颜色但片子里只拍到黑白两个，就只有两个文件夹；没认到任何产品的素材只在左栏，右栏底部会写明还剩几条没归入。
- 产品清单按“一款一个颜色一条”从 brief 里读出来，每条带自己的参考图：brief 给了黑白两色就认这两色，实拍里认出哪一款就归哪一款，不会把黑色的参考图当成米白款。
- 模型不认识、又不像背景或设备的东西会被标成“待确认”，在识别结果里直接问你“这是竞品吗”；确认过一次就写进产品档案，之后每次识别都按竞品判断，不用再问。
- 竞品要问得全：除了“看不出是什么”的东西，**看得出是产品但不是这次那款**的（别家品牌、别家同类）也会被单独标成“别的产品”冒出来问你——以前这种会被当成普通陪衬混过去，竞品就这么漏掉了。确认过的竞品会进产品档案，之后的识别提示词里直接带上。
- B-roll 卡片显示这条素材的主角与待确认件数；右侧识别结果新增“画面里的物品”“焦点走向”“逐帧结论”三块，能看出每一帧里有什么、焦点落在谁身上。
- 认出物品之后要能找得到：搜索框现在也匹配物品的名字、颜色、SKU 和角色（搜“黑色”“UL1-IV”都能定位到素材），素材库顶部多一个“只看待确认”，专门处理模型不认识、你还没确认过的东西；确认之后它就不再出现。
- 识别结果可以直接在视频里核对：每件物品旁边有“看 0:02.4”，焦点走向里的时间码也能点，预览会跳到那一刻，用来确认“这件是不是它、是不是这一款”。
- 修掉一个会丢结果的问题：画面内容识别（Vision）和物品识别是两条独立管线，之前后跑的那条会整体覆盖另一条的结果，现在只补自己那一层——点“AI 识别未识别”不会再把你刚认出来的物品清掉。
- 识别一整批时不再“看着像卡住”：每条素材会显示跑到第几帧（本地模型每条要问 5 次），失败的那几条会明确报出来，而不是混在“认完了”里；开始前也会写明这一批要问多少次。
- 只跑过物品识别的素材不再被当成“已识别画面内容”：卡片不会再拿着默认值说它是“固定镜头”，那类素材会写明“只认过物品，还没看画面内容”，并给一个“补一次画面内容”。
- 新增**本机视觉模型**（Qwen3-VL 8B，跑在 llama.cpp 上）：逐条看 B-roll，判断这一条有没有拍到产品、哪一段产品最清楚；模型运行时和权重下载到 `~/Library/Application Support/CodeCut/`，不进 App 包，素材不出这台电脑，断网可用。
- 产品镜头的结论分四档（产品主体 / 含产品 / 疑似产品 / 未见产品），落成“推荐片段”的起止时间；选片段时以产品是否清楚为主，同时要求这一段镜头稳——镜头在晃的部分不会被算进推荐片段，动得明显的片段会在依据里写明“不适合做定格”。
- B-roll 卡片和右侧详情会显示产品徽章、推荐分、推荐时间码和判断依据（只讲“能不能用来展示产品”，不描述镜头语言）；媒体库新增产品档位筛选和“按推荐分排序”。
- 挑中的片段可以一键“加入分镜表”，把“用哪条素材的哪一段”带进分镜，后面按分镜剪即可。
- 没拍到产品、或者产品片段太短的素材会明确给出原因，不会被硬塞进分镜表。
- 新增 **文稿工作区**（工作区顺序改成 文稿 / 口播 / B-roll / 分镜，文稿排在最前面）：一个项目该先有的几份文稿集中在一页——产品 brief、要读的文字稿、自己写的分镜稿。这一页刻意不做视频预览，看稿子的时候不需要画面。
- 产品 brief 从 B-roll 页搬进文稿页统一管理：读 brief、加参考图、看解析出来的产品档案都在这里。
- brief 不再只认 PDF：Word（.docx）、PPT（.pptx）、图片、RTF、HTML、纯文本都能直接读，老式 .doc / .ppt 交给系统转一次文本。Word / PPT 是在本机解包读 XML 和里面内嵌的图，不用装 Office，左栏还能为它们生成一份能翻的 PDF 预览。
- 文稿页的 brief 改成左右两栏：左边是 brief 原文件，能上下翻、能放大缩小、能按宽度铺满；右边是本机模型读出来的东西——产品是什么、长什么样、必须认出的特征、容易认错的干扰项，以及从 brief 里提出来的产品照片。原来的「补充说明」输入框删掉了。
- PDF 里的产品照片改成直接抠真图：顺着页面内容流找到每一张图的对象，本来就是 JPEG 的直接取原始字节，剩下的才从高分辨率页面渲染里裁。以前整页渲染当候选图，页面的标题和正文都会被一起带进参考图。
- 参考图不再按“画面里内容多不多”排：一份 brief 里几乎每页都嵌着照片，满幅人像和满幅产品照得分一样高，排序就退化成按页码取前几张，挑出来的全是封面和理念页的氛围照，模型照着这些图自然认不准实物。改成按**图挂在哪一页**排——产品参数页上的照片才是这一版产品的官方外观，品牌页 / 用户画像页 / 达人页直接扣分排除，同一页最多挑两张，免得一个图多的页面把名额占满；模型挑完还会做一次确定性纠偏，每个颜色款的第一张参考图必须是参数页上的那张。
- 自己写的分镜稿改成**表格**，并且按你给过来的格式原样呈现：表头就是「文稿 / 分镜 / 镜头类型 / 是否拍摄 / 备注」，一行一个镜头，第一列保留整句台词不被逗号切碎。导入 CSV、导出 CSV 都是同一套字段，Excel / 腾讯文档导出来的文件直接就能用。
- 分镜稿表格可以直接改：每个格子都是输入框，点进去就改；鼠标移到表头右边缘拖动能调**列宽**，移到行底边拖动能调**行高**，两侧都有对应的光标提示；行号右键插入/删除行，表头右键插入/删除列。列宽行高跟项目一起保存，下次打开还是你调好的样子。
- 分镜稿跟着项目走：导入、改内容、调列宽行高都写进项目文件，换项目不会串；以前贴在文本框里的分镜稿第一次打开时会自动搬进表格第一列，不丢内容。
- 文稿页只放文稿：不放视频预览，也不放分镜表和时间轴（右半边的播放器/时间线整块去掉，文稿区横向铺满）。
- 分镜页的「分镜」就是文稿页的那份分镜稿：两个页面读写同一份表格数据，在分镜页改一个格子，回文稿页看到的就是改过的内容，反过来也一样，不存在两份要对齐的稿子。分镜页左侧顶部多了「分镜稿 / AI 分镜参考」切换，默认停在分镜稿；AI 根据剪辑后字幕生成的那张细表（时间码/景别/镜头运动/素材元素）挪到第二个页签，没有被删掉。
- 文稿页的几份文稿和文字稿的审阅结果都跟着项目走：换项目就换成那个项目的内容，不会串。

## 首个可用版本

- 项目级视频、文字稿、AI 对话与自动保存/备份恢复。
- 分段转写、断句、语音边界检测与转写缓存。

- MP4 原生导出，可选烧录字幕；同时支持 SRT、EDL JSON 和 FCPXML。

## 系统要求

- macOS 15.0 或更高版本。
- Apple Silicon Mac。
- 逐词转写在本机完成（首次使用需下载并缓存 WhisperKit 模型）；AI 分析与断句需要有效的 DeepSeek API Key 和网络连接。

AI 断句、口误与去重建议为参考结果，重要成片请在导出前试听并微调。
