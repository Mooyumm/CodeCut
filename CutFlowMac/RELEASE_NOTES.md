# CutFlow 1.0.0（Build 1）

发布日期：2026-08-15

## 首个可用版本

- 项目级视频、文字稿、AI 对话与自动保存/备份恢复。
- MiMo V2.5 ASR 分段转写、断句、语音边界检测与转写缓存。
- 可缩放时间线、播放头、入点/出点、字幕选择/编辑/拆分/合并/删除与撤销重做。
- 视频、原始音频、字幕三轨显示；字幕位于最上方。
- MP4 原生导出，可选烧录字幕；同时支持 SRT、EDL JSON 和 FCPXML。
- API Key 仅存储在 macOS 钥匙串。

## 系统要求

- macOS 15.0 或更高版本。
- Apple Silicon Mac。
- 使用 AI 转写与分析时需要有效的 MiMo API Key 和网络连接。

## 已知限制

MiMo 当前返回转写文本但不返回真实逐词时间戳。CutFlow 会结合 10 秒分段和本地语音边界检测估算时间，精度适合初剪和字幕校对，但不是音素级强制对齐。重要成片请在导出前试听并微调。

当前本机只有 Apple Development 签名时，应用可供本机开发测试；向其他用户分发还需要 Developer ID Application 签名并完成 Apple 公证。
